# 🛒 Full Stack E-Commerce App (MERN)

A complete full stack e-commerce web application built with MERN stack including authentication, payments, real-time features, and scalable architecture.

---

##  Features

-  Authentication (JWT + Google OAuth)
-  Product Management (CRUD)
-  User Profiles
-  Cart & Checkout System
-  Payment Gateway Integration
-  Order Management
-  Image Upload (ImageKit.io)
-  Real-time features (Socket.io)
-  Input Validation (Express Validator)
-  Load Balancer Ready Architecture



-  Tech Stack

# Frontend:
- React.js
- Tailwind CSS / SCSS
- Axios

# Backend:
- Node.js
- Express.js

# Database:
- MongoDB
- Redis

# Other Tools:
- Google OAuth
- ImageKit.io
- Socket.io
- Express Validator
- JWT Authentication
